## ID の読み方（🔴 **住所は節番号ではなく ID**。`grep -rn NG07 docs/` がそのまま索引）

| 記号 | 種類 | 例 | 置き場所 |
|---|---|---|---|
| **`DC`** | **設計上の選択**（＝ 次の一手の候補）。**D**esign **C**hoice | `DC05`, `DC05b` | [`NOW.md`](NOW.md) register |
| **`NG`** | **否定結果**（前提つき）。**N**o **G**ood | `NG07` | [`NOW.md`](NOW.md) 否定結果の棚 |
| **`EX`** | **測定 1 本**。族に紐付けない**全体通番** | `EX001` | [`EVIDENCE.md`](EVIDENCE.md) |
| 版 / 提出 | ファイル名・提出番号がそのまま ID（**新しい名前を作らない**） | `07_beam.rs`, 提出#3 | [`VERSIONS.md`](VERSIONS.md) |

> 🔴 **一度振った ID は動かさない**（枝分かれは `DC05b`）。**手書きの索引表は分割のたびに腐るので置かない。**
> 🔴 **ID を振るのは「多くて・名前が無くて・後で指し直すもの」だけ。** 少なくて既に名前があるもの（版・提出・
> 証拠の族）には ID を作らない ── 別名は二重管理になる。⚠ **単一文字（`A` `B` `C`…）は使わない**（必ず衝突する）。
