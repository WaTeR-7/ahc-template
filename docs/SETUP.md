  `cargo run -r --bin gen seeds.txt`。⚠ **`gen` は seeds ファイルの*行番号*でファイル名を決める**
  ⇒ 追加生成は必ず `--dir <別ディレクトリ>` に出す。採点器は `../scripts/test.sh` の `SCORER` を編集。
