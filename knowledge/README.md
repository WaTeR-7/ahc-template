# knowledge/ — 過去コンテストの分析（現在のコンテストで使うための置き場）

**このフォルダはテンプレに同梱される** ＝ `new.sh` で作った新しいコンテスト repo にそのままコピーされる。
だから**コンテスト開始時に「過去の自分の分析」が手元にある**。

## 正本はどこか

- **正本は `~/ahc/template/knowledge/`。** コンテスト repo 側にあるのは**コピー（読み取り専用）**。
- **コンテストが終わったら、そのコンテストの分析を書いて `template/knowledge/` に置く**（正本を更新する）。
  コンテスト repo 側のコピーを編集しても次に伝わらない。

## 3層の棲み分け

| 層 | 場所 | 中身 | 性質 |
|---|---|---|---|
| ルール | `CLAUDE.md` | **毎回必ず従うこと**（一般化済み） | 恒久・短い・根拠は1行 |
| **分析** | **`knowledge/ahcNNN.md`** | **1コンテストの分析。ルールの根拠、まだ一般化できていない知見** | 蓄積・詳しい |
| 一次資料 | 各コンテスト repo の `LOG.md` | 生ログ（測定値・経緯・全アプローチ） | private repo に残る |

- `CLAUDE.md` のルールは短く保つ（「ahc068 は幅1で4倍」のような1行）。**その1行の裏側がここにある。**
- **同じ知見が2回目のコンテストで出たら `CLAUDE.md` のルールに昇格させる**（1回だけならここに置いておく）。
  昇格したらこのファイル側に「→ CLAUDE.md 済」と印をつける（どちらが正かを迷わないため）。
