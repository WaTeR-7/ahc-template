# 見込みつき貪欲 — 「あと数枚で置ける手」を解析的な確率で値付けして、1 手を選ぶ

**一言で**: 毎ターン、今置ける手と一緒に「**手札に無い札が k 枚来れば置ける手**（見込み）」まで列挙し、
`得点 × 足りない札が H 枚の補充のうちに来る確率` で値付けする。行動の値 = 今の得点 ＋ その行動が残す見込みの最大。値が最大の行動を出す。
**乱数で先を引かず、確率を表から直接計算する**のが要点（大当たりが稀な問題で、試行では拾えないため）。

> この記事は MM167（スクラブルの 1 人版・対話）で使った範囲の記録。

## 他の手法との対比

| | **見込みつき貪欲** | 素の貪欲 | 先を乱数で引くロールアウト（MC） | 計画を本体にする（線と語を決めて揃える） |
|---|---|---|---|---|
| 待つ（捨てる）判断 | ○ 置く手と捨てる手を同じ値で比べる | × 置けないときだけ捨てる | ○ | ○ |
| 稀な大当たり（数 % で揃う手） | ○ 確率をそのまま掛ける | × | **× 数十回の試行では拾えない** | ○ |
| 2 ターン以上先の準備 | △ 項を足して近似（仕込み・狙う線の表）。**項にすると毎ターン入れ替わる** | × | △ 深さの中で揃う分だけ | ○（未実装） |
| 時間を増やすと | 数え直す手の数を増やす分だけ伸び、64 で鈍る | 伸びない | 伸びる | — |

## いつ使うか（構造カルテの軸）

- **向く**: 軸1 = 取り消せない逐次決定で、**先の入力が既知の分布からの独立な乱数**（軸7 で生成則が公開）／
  軸2 の得点が**少数の大きい手に集中**していて、その大きい手が「あと数枚」で揃う形（MM167: あと 1 枚あれば置ける手の最高点は、今置ける手の中央 2.17 倍）／
  **1 ターンの合法手の全列挙が安い**（MM167: 1 ms 未満）。
- **向かない**: 🔴 **大きい手が 2 ターン以上の準備（足場を置く・狙いを守る）を要する**とき。項を足して近似はできるが、
  今の手札での値付けに引きずられて**狙いが毎ターン入れ替わる**（→ [plan-persistence-trace](../techniques/plan-persistence-trace.md)）。そこが主戦場なら計画を本体にした形と比べる。

## 中身（MM167）

- **列挙**: 線（行・列）ごとに辞書のトライを辿る。手札に無い札を `K = 2` 枚まで（得点が大きい手は 3 枚まで）「あるもの」として辿れば、合法手と見込みが 1 回の列挙で出る。
- **見込みの値**: `v(w) = score(w) × Π_ℓ P(H 枚のうちに文字 ℓ が c_ℓ 枚以上)`。`c_ℓ` = 足りない枚数。先読みの札は確定として手札に数え、
  その先は文字ごとの二項分布の表（`n` 枚引いて `c` 枚以上の確率。`n ≤ 64`・`c ≤ 4`）を引いて、**文字どうしは独立とみなして掛ける**。`H = 32`。
- **行動の値**:
  - 置く手 `m`: `score(m) − pen(m) + max_{w ∈ W(m)} v(w)`。`W(m)` = `m` を置いた後も置ける見込み。
  - 捨てる `d`: `−D + max_{w ∈ W(d)} v(w)`。残す札の候補は「見込みの上位 24 件が要る札」と「全部捨てる」。**置ける手があっても捨ててよい**。
  - 値引き `pen`: 倍率のマスを、その窓の最大の積の半分に届かない倍率で踏むと 1 マスあたり窓の積 ＋ 札 1 枚 3 点。前者は残りの札が `0.3 N²` を切ったら線形に弱める。
- **数え直し**: 上の値では「`m` を置いて新しく生まれる見込み」が入らない ⇒ 値の上位 `C = 32` 手だけ、実際に置いた盤で（`m` が変えた線だけ）列挙し直す。
  `m` で空いた手札に必ず入る先読みの札は手札に入れて数える。

## 骨格

```
for turn:
  enumerate(board, hand, K)          -> legal moves M, prospects P (with missing multiset)
  for m in M: val1[m] = score(m) - pen(m) + max{ v(w) : w in P, m does not destroy w }
  for d in discard candidates: val[d] = -D + max{ v(w) : w in P(hand - d) }
  for m in top C of val1:            # re-count on the board after m (affected lines only)
    P' = enumerate_lines(board + m, hand - m + known_next, K)
    val[m] = score(m) - pen(m) + max{ v(w) : w in P' } (+ 他の項)
  output argmax val
```

## 実装の要点 / 調整点

| ノブ | MM167 で分かったこと |
|---|---|
| 見込みの不足の枚数 `K` | 1 は −6.4%、3 は差なし。得点の大きい手だけ 3 枚まで広げて +2.35% |
| 補充の枚数 `H` | 32。8・16・64 はどれも負け |
| 見込みの重み α | 100% が山（75%: −3.9%、125%: −20.5%）。**値の形・割引と釣り合っている**ので単独で動かさない |
| 数え直す手の数 `C` | 倍にするたび +2.5〜3.6%、64 で鈍る。数え直しは「その手で変わる線だけ」で全線と差なし・3.6 倍速い |
| 捨てる候補 | 候補に入れないと −6.6% |
| 時間 | 時間を見ない走行の 1 ターンの時間の形で予算を配り、超えたら倍率の小さい線から見込みを落とす（→ [time-shape-allocation](../techniques/time-shape-allocation.md)） |

## 落とし穴（効かなかったもの。どれも「その時の値の形の下で」）

- 🔴 **見込みの値を「正しく」数え直すと負ける**: 1 語ずつの最大の代わりに、和・log-sum-exp（線ごと・語ごと・足りない札の組ごと）・期待される最大・
  「この補充だけで揃う確率」の混合、どれも差なしか負け（確率どおりに足す「期待される最大」は −5%）。
  今の値（1 語の最大 × 32 枚のうちに揃う確率）は確率を大きく見積もっていて、**割引と重みがそれを打ち消す形で釣り合っている**。数え方だけを正しくすると釣り合いが崩れる分が勝つ。
  ⇒ 値の形を変えるなら、割引・重みを一緒に測り直す。
- **MC（補充を乱数で引いて次のターンの見込みを数える）**: +0.25%・+0.59% で差なし。大当たりは数 % でしか揃わない。
- **「窓を開ける」ことへの加点**: −3.4%・−21%。開いたかではなく、そこに置ける語と確率まで数えないと値にならない（数えた形が [fixed-input-potential](../techniques/fixed-input-potential.md)）。
- **2 ターン以上先の準備を項で足す**と、狙いが毎ターン入れ替わる（57.6% が 1 ターン・置かれたのは 1.1%）。狙いを引き継ぐ重みは強くするほど負け。

## 実績

- **MM167**: 初日に素の貪欲比 `Δlog +64%`（dev +63.7%・holdout +64.5%。暫定 27.3 → 46.0）。その上に仕込み・狙う線の表・場所の値・時間の配り方・遠い表を足して 1 割強。
  最終 27 位。首位とは暫定で 1.8 倍の差が残った（[`contests/mm167.md`](../contests/mm167.md)）。
