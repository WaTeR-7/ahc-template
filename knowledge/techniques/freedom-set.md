# 自由度管理（1手を確定させず「同じ効果を与える手の集合」で持つ）

**主張**: 操作を1つに即確定せず、**同じ効果を与える操作の候補集合**として保持する。後から要求（相乗りさせたい／
確定済みを守りたい）が来たときに、集合を絞る形で応える。**確定を遅らせるほど、後の要求に応えられる。**

## 適用条件（構造カルテの軸で）

- **軸3**: 同じ効果を与える手が**複数ある**（パラメータに自由度がある。ahc068 は「同じ変位を与える矩形」が
  平均4通り、17.5% は自由度ゼロ）
- **軸5**: 決定が後の自由度を削る（干渉がある）。干渉が無いなら遅延の価値も無い
- 相乗り（[ride-along](ride-along.md)）と組む前提。単独では効果が小さい

## 機構（ahc068 の例）

`V` 操作は「進行軸のサイズが 2d に固定、位置は自由」＋「垂直軸は前後に独立に伸ばせる」ので、
**3方向 × (下限, 上限) = 6変数**で族を表現できた。

- **下限**は相乗りに使う（このカードを含めるには、ここまで伸ばす必要がある）
- **上限**は保護に使う（確定済みを壊さないために、ここまでしか伸ばせない）
- 「同じ手数で選べる候補」の採点は**距離ではなく手数下限（floor）の変化**で行う
  （距離で採点すると、点にならない量を最適化してしまう ── ahc068 の敗因と同じ罠）

**細い矩形が損をしない理由**: 壁フリーな太い矩形の部分矩形は必ず壁フリーで、**同じ変位**を与える。
⇒ 手数は同じで巻き込む対象だけ減る。だから「巻き込みを意図的に使う」段（相乗り）と組み合わせて初めて価値が出る。

## 効果（ahc068）

- **+12.15M**（近視眼的な上限は 3.2 倍だったので、大部分は取り逃がしている）
- 取り逃がす機構も分かっている: **1枚は配達まで 30〜55 回動かされる**ので、1回の賢い選択が希釈される。

## 出典

概念（長方形の確定を遅らせ、候補集合として更新する ＝「自由度管理」）は **AHC068 の writer が公表した
想定解**に由来する。延長戦で読んで自分で実装した（→ [ride-along](ride-along.md) の出典欄と同じ扱い）。
6変数での表現と floor による採点は自作。
