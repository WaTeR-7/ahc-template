# lib/ — 再利用部品の一覧

**使い方は 1 つだけ**: 解答は `lib` を **`use` しない**。必要な `mod` ブロックを **`lib/<name>.rs` からコピペ**する
（自己完結でそのまま提出でき、その場で改造できる。bundler は使わない）。
`lib/` は cargo の lib ターゲット `ahc_lib`（`lib.rs` が `include!`）なので、**`cargo check` / `cargo test` で
型検査とテストが通る**＝ ここが**検証済みの正本**。部品を足したら `lib.rs` に `include!` を 1 行足す。

**各ファイルの先頭に「何のためにあるか・使い方・落とし穴」が書いてある**ので、詳細はそちらを読む。
**探索の骨格（`anneal` / `beam` / `perm`）は先頭コメントにループ本体の雛形がある** ── 埋めるだけで動く。

## 1. 骨組み（ほぼ毎回貼る）

| 部品 | 何をする | 落とし穴 |
|---|---|---|
| [`io.rs`](io.rs) | **入出力**。`Scanner`（stdin 一括読み・**バッチ用**）/ `Interactor`（1 行ずつ・**対話用**）/ `Writer`（共通出力。整数は手書き itoa で `core::fmt` を回避） | 🔴 **対話問題に `Scanner` を使うと EOF 待ちで固まる**。問題形式で選ぶ |
| [`timer.rs`](timer.rs) | **時間**。`Timer`（`AHC_TL` を締切に）と **`Budget`（作業量カウンタ）** | 🔴 **壁時計は最外の締切だけ。内部段を壁時計で切ると解が非決定的になり、掃引の比較も `same.sh` も壊れる** ⇒ 内部は `Budget` |
| [`env.rs`](env.rs) | **チューナブルの読取り**。未設定・パース失敗は既定値 | **新しいレバーの既定は OFF**（そのまま「OFF で前版と byte 一致」の検証に使える） |
| [`rng.rs`](rng.rs) | 乱数 splitmix64（`below` / `range` / `f64` / `shuffle` / `pick`）。高速・種から決定的 | 種を固定しないと掃引が再現しない。`below`/`range` は剰余なので厳密には一様でない |

## 2. 探索の骨格（**短期戦の主戦力**。中身を埋めるだけで動く形にしてある）

| 部品 | 何をする | 落とし穴 |
|---|---|---|
| [`anneal.rs`](anneal.rs) | **焼きなましの運転席**。温度スケジュール（幾何冷却）/ 進行度 / 時間チェックの間引き / 受理判定 / 受理率の統計。状態と近傍は持たない | 🔴 **温度はスコアのスケールで決める**（`report()` の受理率を序盤 30〜50% に合わせるのが一次判定）。🔴 **best は現在解と別に持つ**。🔴 `AHC_ITERS=N` で**反復数ベースの決定モード**になり `same.sh` の byte 一致検証に使える |
| [`beam.rs`](beam.rs) | **ビームの道具 3 点**。`Tree<Op>`（親リンクだけで手順復元）/ `sort_top_k_by`（`select_nth_unstable` で O(n) 選抜）/ `Set64`（u64 の高速 dedup・`clear` で使い回す） | 🔴 **選抜 → 重複除去の順**。逆にすると遅く、この順だと W を割るので**多めに選抜する**。**状態を全層ぶん持たない**（手順は `Tree` から復元） |
| [`perm.rs`](perm.rs) | **順列（巡回路）の近傍と差分**。`two_opt` / `or_opt`（区間移動・反転つき）/ `swap`。**全部が総当たりで再計算と一致検証済み** | 🔴 **返る delta は「コストの増分」= 小さいほど良い**。`anneal` は最大化前提なので符号を反転して渡す。🔴 **2-opt と or-opt の `rev=true` は距離が対称でないと合わない**（非対称なら `or_opt` の `rev=false` だけ） |
| [`zobrist.rs`](zobrist.rs) | **Zobrist ハッシュ**。差分更新 `O(1)`（`h ^= at(slot,a) ^ at(slot,b)`） | ビーム/焼きなましの**状態 dedup**（`beam::Set64` に入れる）。自己完結（`rng` 不要） |

## 3. 盤面・グラフ

| 部品 | 何をする | 使いどころ |
|---|---|---|
| [`grid.rs`](grid.rs) | **格子**。1 次元 id ⇄ 座標（`id` / `rc`）、4 近傍（方向つき `for_each_neighbor_dir` あり）、BFS 最短距離（辺重み 1）、`DIR` / `DIR_CHAR` / `manhattan` | 「セル間に壁がある H×W」型。**壁を立てなければ素の格子**としても使える。🔴 **`DIR_CHAR` の順序は問題ごとに違う。条文を見て必ず差し替える** |
| [`dijkstra.rs`](dijkstra.rs) | **重み付き最短路**。`dijkstra`（非負重み）/ `bfs01`（重み 0/1・deque）。どちらも**複数始点**対応、`restore_path` で経路復元 | 移動コストが場所で違うとき（`grid` の BFS は辺重み 1 専用）。⚠ 大きな格子を展開すると辺が 4HW 本になる |
| [`dsu.rs`](dsu.rs) | **Union-Find**。`Dsu`（経路圧縮）と **`RollbackDsu`（巻き戻せる）** | 連結性の制約・グループ分け。🔴 **焼きなましで「試して戻す」なら `RollbackDsu`** ── 経路圧縮した `Dsu` は巻き戻せない |
| [`artic.rs`](artic.rs) | **関節点**（Tarjan の lowlink）。取り除くと連結成分が増える頂点を全列挙 | 「そのセルを消すと残りが分断されるか」＝ **連結性を保つ順序**の判定。⚠ DFS が再帰なので巨大グラフではスタックに注意 |
| [`matching.rs`](matching.rs) | **二部マッチング**（Kuhn。`O(V·E)`） | 割当・辺彩色・行/列整列。数百〜数千頂点なら十分速い |

## 4. 計測

| 部品 | 何をする | 落とし穴 |
|---|---|---|
| [`sprof.rs`](sprof.rs) | **命令の番地を一定間隔で採るプロファイラ**（SIGPROF。集計は `scripts/sprof.py` で関数・行ごと） | 🔴 **細かい区間ごとにタイマーを挟む計測は軽い段を水増しする**（ahc072: 3〜4 割に見えた段が実際は 1 割、本命は別の段）⇒ 内側ループの中の割合はこちらで見る。x86_64 Linux 専用。標本の間隔はカーネルの刻みで決まるので何十件か走らせる。提出する版には貼らない |
| [`prof.rs`](prof.rs) | **段別の呼び出し回数と経過時間**（自前プロファイラ。`ON=true` で有効化） | 🔴 **推測で削ると外す**。**「回数 × 1 回のコスト」を分けて出す**まで削り所は見えない（ahc068: 同じループ内の O(N) 19.7M 回 と O(1) 25.3M 回。間引くべきは前者だった）。⚠ **段の割合が分かっても「段の中で何が高いか」は別問題**（ahc069 で 2 連続で外した） |

## 部品を足すとき

1. `lib/<name>.rs` に **そのまま貼れる `mod` ブロック**として書く（1 種類 1 ファイル）。
2. **先頭に「何のためにあるか / 使い方 / 落とし穴」**を書く ── 後で選ぶときに読むのはここ。
   **骨格系はループ本体の雛形も置く**（本番に思い出す時間はない）。
3. `lib.rs` に `include!("<name>.rs");` を 1 行足す。
4. `cargo check` / `cargo test` を通す（**解答側にコピペする前に**ここで型検査を済ませる）。
   **index 計算のような「合っているか目で見て分からない」ものは、素朴な再計算との総当たり照合**で検証する
   （`perm.rs` がこの形。→ [`../knowledge/techniques/equivalence-by-assert.md`](../knowledge/techniques/equivalence-by-assert.md)）。
5. 汎用の**手法・テクニック**として残すなら、記事は [`../knowledge/`](../knowledge/README.md) 側に書く
   （`lib/` はコード、`knowledge/` は「いつ使うか」）。
